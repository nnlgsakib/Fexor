Set up this kiosk

1Choose the camera

Pick the picture that shows the person standing at the kiosk.

Use a phone or network camera

In the DroidCam app (or similar), find the Wi-Fi address and type it here, for example http://192.168.1.5:4747/video.

2Connect to your server

On a computer, open the admin panel, go to Kiosks and click Add kiosk. Hold the QR code it shows in front of this camera.
